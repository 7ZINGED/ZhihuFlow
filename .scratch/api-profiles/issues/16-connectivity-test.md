# 16: AI 平台连通性测试

**What to build:** 用户能在设置面板对指定 API 配置档案做一次极小真实请求，立即看到成功耗时与返回模型名，或分类后的失败原因，用于确认接口、模型与 Key 是否可用。

**Blocked by:** 15

**Status:** done

**Parent spec:** `.scratch/api-profiles/spec.md`

- [x] AI 模块导出一个连通性测试公共函数，接受档案、复用现有端点规范化与 HTTP 错误映射
- [x] 测试请求是 OpenAI 兼容 `chat/completions`，`max_tokens=1`，不产生可观额度消耗
- [x] 测试按钮使用正在编辑的档案值（含未保存的 Key），而不是已保存的旧值
- [x] 成功时显示耗时和返回模型名；失败时按配置缺失 / 鉴权失败 / 网络不通 / 响应异常分类提示
- [x] 测试进行中与结果状态在 UI 可见，按钮不误触发重复点击
- [x] 连通性测试函数有公共缝测试：极小请求体、成功结果与各失败分类；组件不直接 fetch
