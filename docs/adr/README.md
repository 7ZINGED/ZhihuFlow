按编号递增，一条决策一个文件。状态为「已接受」的条目是当前约束；要推翻它，新开一条 ADR 并在其中引用被取代的编号，不要直接改写历史。

## 写新 ADR 的时机

- 决定了两个方案之间的取舍，且后来者可能想改回去。
- 出现"为什么不能这样做"的反复解释。
- 推翻了既有 ADR。

词汇与阶段命名以 `GLOSSARY.md` 为准。
